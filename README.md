# Гид фестиваля уличных театров «Елагин парк»

Мобильное одностраничное расписание XIV Международного фестиваля уличных
театров «Елагин парк», 24–26 июля 2026 года.

В интерфейсе доступны:

- навигация по времени;
- режимы «в это время», «в течение часа» и «весь день»;
- фильтры по нескольким площадкам и возрастным ограничениям;
- поиск по спектаклям и театрам;
- компактные карточки мероприятий;
- мобильная нижняя навигация.

## Локальный запуск

Требуется Node.js 22.

```bash
npm ci
npm run dev
```

## Развёртывание в Vercel

1. Импортируйте этот репозиторий в Vercel.
2. Оставьте Framework Preset: `Next.js`.
3. Нажмите Deploy.

Файл `vercel.json` уже задаёт Vercel отдельную стандартную Next.js-сборку:

```bash
npm run build:vercel
```

Дополнительные переменные окружения для расписания не требуются.

## Другие команды

- `npm run lint` — проверка кода;
- `npm run build:vercel` — проверка сборки для Vercel;
- `npm run build` — сборка исходной версии для ChatGPT Sites.
